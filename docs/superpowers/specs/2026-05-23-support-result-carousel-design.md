# 辅助结果工作区：顶部标签 + 横向滑动设计

日期：2026-05-23

## 背景

实时练习页目前在用户点击「建议回答」「换个更自然表达」「问一个探索问题」「使用材料要点」后，会把结果模块直接纵向陈列在实时字幕下方。用户连续触发多个辅助模块时，页面会变长，当前重点模块不突出，也不方便在多个分析结果之间来回比较。

本设计采用方案 A：在实时字幕下方建立一个统一的「辅助结果工作区」，通过顶部横向标签管理多个已生成模块，主体区域只展示当前选中的模块。

## 设计目标

- 用户点击多个辅助按钮后，结果不再纵向堆叠。
- 点击新模块后，界面自动切到该模块。
- 已打开模块可以通过顶部标签左右滑动并点击切换。
- 每个模块都有关闭按钮，可以单独关闭。
- 主对话和实时字幕保持视觉中心，辅助结果只在需要时出现。
- 支持建议回答、换个更自然表达、问一个探索问题、使用材料要点、挑战我。

## 非目标

- 不改变各模块后端 AI 生成逻辑。
- 不改变实时语音对话链路。
- 不新增复杂的历史记录管理。
- 不把辅助结果持久化成跨会话标签页；当前设计只管理本次页面内打开的结果。

## 页面结构

实时练习页主区域顺序调整为：

1. 实时语音练习卡片
2. 系统状态提示
3. 实时字幕
4. 辅助结果工作区
5. 右上角悬浮提示按钮

右侧或底部提示面板继续保留「智能建议」和触发按钮。提示面板负责触发动作，辅助结果工作区负责阅读、切换和关闭结果。

## 辅助结果工作区

工作区只在至少存在一个结果模块时显示。

结构：

```text
辅助结果工作区
[ 建议回答 × ] [ 更自然表达 × ] [ 探索问题 × ] [ 材料要点 × ]

当前选中模块内容
```

顶部标签栏：

- 横向排列所有已打开模块。
- 当前选中标签使用主色背景或主色边框强调。
- 未选中标签使用浅色边框。
- 标签内包含图标、标题、状态和关闭按钮。
- 标签栏在移动端和窄屏下可横向滚动。

主体区域：

- 只展示当前选中模块。
- 不展示其他模块内容。
- 切换标签时，主体内容替换为对应模块。

## 模块类型

### 建议回答

标题：建议回答

内容：

- AI 客户原句
- 上下文解析
- 语句逻辑拆解
- 如何回应
- 推荐回复
- 高级词汇

触发行为：

- 点击「建议回答」后创建或激活建议回答标签。
- 如果没有 AI 客户问题，显示错误状态标签和错误说明。
- 生成成功后自动切到该标签。

### 换个更自然表达

标题：更自然表达

内容：

- AI 客户上下文
- 你的原句
- 语句逻辑拆解
- 更自然表达
- 为什么更好
- 高级词汇

触发行为：

- 点击后创建或激活更自然表达标签。
- 生成成功后自动切到该标签。

### 问一个探索问题

标题：探索问题

内容：

- 当前上下文判断
- 推荐问题
- 中文含义
- 建议原因

触发行为：

- 点击后创建或激活探索问题标签。
- 生成成功后自动切到该标签。

### 使用材料要点

标题：材料要点

内容：

- 可引用材料要点
- 建议表达

触发行为：

- 点击后创建或激活材料要点标签。
- 生成成功后自动切到该标签。

### 挑战我

标题：挑战我

内容：

触发行为：

- 点击后创建或激活挑战我标签。
- 不触发 AI 客户继续说话，只生成分析模块。

## 交互规则

### 打开模块

用户点击提示按钮时：

1. 如果该类型模块尚未打开，创建一个新标签。
2. 新标签状态先进入 `loading`。
3. 页面自动切换到该标签。
4. AI 请求完成后，标签状态变为 `ready` 并展示内容。
5. 如果请求失败，标签状态变为 `error` 并显示重试按钮。

### 再次点击已打开模块

默认行为：

- 不重复创建标签。
- 直接切换到已有标签。
- 不自动重新请求 AI。

在模块主体右上角提供「重新生成」按钮，用于重新请求 AI。

### 关闭模块

每个标签右侧都有关闭按钮。

关闭规则：

- 关闭非当前模块：只移除该标签，当前模块不变。
- 关闭当前模块：
  - 优先切到左侧相邻模块；
  - 如果左侧没有，切到右侧相邻模块；
  - 如果没有剩余模块，隐藏整个辅助结果工作区。

### 切换模块

用户可以：

- 点击标签切换。
- 在移动端横向滑动标签栏后点击目标标签。

主体区域不做整卡横向滑动，避免和页面纵向滚动冲突。

## 状态模型

新增统一结果标签模型：

```ts
type SupportResultTabType =
  | "suggested-answer"
  | "better-phrase"
  | "discovery-question"
  | "material-point"
  | "challenge-me";

type SupportResultTabStatus = "loading" | "ready" | "error";

type SupportResultTab = {
  id: string;
  type: SupportResultTabType;
  title: string;
  status: SupportResultTabStatus;
  createdAt: string;
  payload?: SuggestedAnswerRecord | SupportCueResult;
  errorMessage?: string;
};
```

页面状态：

```ts
const [supportResultTabs, setSupportResultTabs] = useState<SupportResultTab[]>([]);
const [activeSupportResultTabId, setActiveSupportResultTabId] =
  useState<string | null>(null);
```

说明：

- `supportResultTabs` 保存所有当前打开模块。
- `activeSupportResultTabId` 决定主体展示哪个模块。
- 旧的 `suggestedAnswer`、`supportCueResult` 可以逐步收敛到这个统一模型。

## 组件拆分

建议新增组件：

### `SupportResultWorkspace`

职责：

- 接收所有结果标签。
- 渲染顶部横向标签栏。
- 渲染当前选中模块。
- 处理关闭、切换、重试事件。

### `SupportResultTabs`

职责：

- 只负责标签栏。
- 支持横向滚动。
- 展示状态：生成中、完成、失败。
- 每个标签提供关闭按钮。

### `SupportResultContent`

职责：

- 根据 tab type 渲染不同内容。
- 复用已有的 `SuggestedAnswerPanel` 和 `SupportCueResultPanel` 展示逻辑。

## 视觉规范

工作区卡片：

- 使用现有卡片样式，保持 `rounded-md`。
- 不嵌套多层大卡片。
- 背景使用 `var(--surface)`。
- 边框使用 `var(--border)`。

标签：

- 当前标签：主色边框或浅主色背景。
- 未选中标签：白底浅边框。
- loading：显示小型加载状态。
- error：显示警告色状态点。

关闭按钮：

- 使用 `X` 图标。
- 点击区域不小于 32px。
- 阻止事件冒泡，避免点击关闭时同时切换标签。

## 移动端

- 标签栏横向滚动，使用 `overflow-x-auto`。
- 标签不换行，避免挤压文字。
- 主体内容占满宽度。
- 工作区位于字幕下方，避免放入底部提示抽屉。
- 关闭按钮保持易点按。

## 桌面端

- 标签栏通常展示 3-4 个标签。
- 如果标签超出宽度，横向滚动。
- 主体内容保持当前宽度，不随标签数量变化。

## 错误处理

模块请求失败时：

- 保留对应标签。
- 标签显示失败状态。
- 主体展示错误说明。
- 提供「重试」按钮。
- 用户也可以直接关闭该模块。

建议回答缺少 AI 客户问题时：

- 创建错误状态标签。
- 主体提示「等 AI 客户提出问题后，再使用建议回答」。

## 测试要求

单元测试：

- 点击建议回答后出现一个标签并激活。
- 再点击更自然表达后出现第二个标签并激活第二个。
- 点击第一个标签可切回建议回答。
- 点击关闭当前标签后自动切到相邻标签。
- 关闭最后一个标签后工作区隐藏。
- 再次点击已打开模块不会重复创建标签。
- 失败状态展示错误内容和重试按钮。

回归测试：

- 建议回答仍然调用 `/suggested-answer`。
- 更自然表达、探索问题、材料要点、挑战我仍然调用 `/support-cue`。
- 点击非建议回答模块不会触发 AI 客户继续说话。
- 实时字幕仍只展示最近 3 轮。

## 验收标准

- 用户连续点击多个提示模块后，页面不会纵向堆叠多个大模块。
- 当前模块始终清晰突出。
- 所有已打开模块可通过顶部标签切换。
- 每个模块可以单独关闭。
- 移动端标签可横向滑动。
- 错误和加载状态不会挤压或破坏布局。
- 现有 AI 分析内容结构不丢失。

## 决策记录

已确认采用方案 A：顶部标签 + 横向滑动结果工作区。

未采用方案 B 的原因：整卡横向滑动与长内容纵向滚动容易冲突。

未采用方案 C 的原因：把长分析放在右侧提示抽屉内会压缩阅读空间，不利于用户复盘和学习。
